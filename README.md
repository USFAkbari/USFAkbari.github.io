# Yousef Akbari — Academic Website

Personal academic website and portfolio of Yousef Akbari (Systems & DevOps Engineer, Prospective M.Sc. Candidate in CS/SE), built using the [al-folio](https://github.com/alshedivat/al-folio) Jekyll template and hosted on [GitHub Pages](https://pages.github.com/).

## Live Website
👉 **[https://USFAkbari.github.io](https://USFAkbari.github.io)**

## Features
- **CV / Resume:** Complete academic and professional resume rendered via JSONResume format and direct PDF download.
- **Projects & Research:** Detailed technical and academic projects (Applied AI, Computer Vision, MLOps).
- **Responsive & Dark Mode Support:** Tailored dark/light academic theme.
- **Automated Deployment:** Continuous deployment to GitHub Pages via GitHub Actions.

## Development & Local Preview
```bash
# Using Docker
docker compose up

# Or using Jekyll
bundle install
bundle exec jekyll serve
```
