### Engineering Overview
Administered and automated production VMware ESXi hypervisors, containerized microservices, and network infrastructure at Khademan Emam Zaman (shamim313.com) and Part Software Group.

### Key Contributions & Achievements
- **High-Availability Cluster Operations:** Maintained multi-node VMware ESXi production environments hosting ~10 production VMs serving over **100,000 registered users** with zero unplanned downtime.
- **Docker Containerization:** Containerized 5+ core backend services, standardizing environments and reducing release deployment times by approximately 10%.
- **Disaster Recovery & Automation:** Implemented automated snapshot and backup pipelines with Veeam and Bash scripting, saving 3–4 engineer hours weekly and mitigating configuration drift.
- **VoIP Telephony:** Maintained zero-downtime operation for 6+ months on enterprise FreePBX VoIP telephony supporting 20+ staff extensions.
- **Storage & Security Policies:** Managed TrueNAS ZFS storage arrays (1–10 TB) with automated snapshot schedules, firewall access control lists, and network segmentation.

### Tech Stack
`VMware ESXi` `Docker` `Docker Compose` `Bash` `TrueNAS ZFS` `Veeam` `FreePBX` `Ubuntu Server`
